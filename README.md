# Pathetic-Skript

A Skript addon for Minecraft servers that provides integration for the Pathetic pathfinding library. You can see Pathetic pathfinding library [here](https://github.com/bsommerfeld/pathetic)

## Features
- Fast entity pathfinding syntax for Skript.
- Customizable movement rules and node limits.
- Performance controls to keep your server running smoothly.

## Installation
1. Make sure you have **Skript** installed on your server.
2. Download the latest `Pathetic-Skript.jar` from the releases page.
3. Drop the file into your server's `plugins/` folder and restart the server.
